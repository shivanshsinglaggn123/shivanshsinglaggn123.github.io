# Slit-pore graph reproduction

This repository contains a Jupyter notebook that reproduces the partition-coefficient graph from the supplied reference figure.

## Files

- `reproduce_graph.ipynb`: explained calculation and plot.
- `reproduce_graph.py`: standalone Python version of the calculation.
- `reproduced_graph.png`: saved plot generated by the notebook.
- `requirements.txt`: Python dependency list.

## Run the notebook

First enter this folder in the terminal:

```bash
cd graph_reproduction
```

Install the dependency:

```bash
python3 -m pip install -r requirements.txt
```

Open the notebook in Jupyter or VS Code, then run the cells from top to bottom:

```bash
jupyter notebook reproduce_graph.ipynb
```

The plotting cell saves the result as `reproduced_graph.png`.

## Model

The calculation uses the slit-pore series

$$K(g,\\lambda)=\\sum_{m\\text{ odd}} \\frac{2\\lambda^2}{\\alpha_m^2(\\lambda^2+\\alpha_m^2+\\lambda)}e^{-\\alpha_m^2g^2},$$

with $g=R_G/R_P$ and interaction values $\\lambda=50,3,0.1,0,-0.1,-3$.
