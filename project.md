## Polymer Partitioning Research

This project studies how polymers distribute inside and outside narrow pores using the theory of chromatography.

The current work has two parts:

- **Homopolymer Graph:** calculates $K$ for a linear homopolymer and compares curves for different polymer-wall interaction values $\lambda$.
- **End-functionalized Plots:** compares ordinary homopolymers with linear chains containing one or two adsorption-active end groups.

The calculations use characteristic roots and sums from the supplied research equations. Python functions calculate the partition coefficient, and Jupyter notebooks show the mathematical steps and generate graphs for investigation.
